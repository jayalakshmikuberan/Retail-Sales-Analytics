# Retail-Sales-An# Superstore Sales Data Analysis

## Overview
This project focuses on analyzing sales data from a retail superstore to understand overall business performance. The analysis explores sales trends, profitability, customer segments, and regional performance using real transactional data.

The goal of this project is to extract meaningful insights that can help improve pricing strategies, identify high-performing regions, and understand product-level performance.

---

## Dataset
- **Name:** Sample Superstore Dataset  
- **Records:** 9,994  
- **Features:** 21  
- **Format:** CSV  

### Key Columns
- Order ID, Order Date, Ship Mode  
- Customer Name, Segment, Region  
- Category, Sub-Category, Product Name  
- Sales, Quantity, Discount, Profit  

---

## Tools & Technologies
- Python  
- Pandas & NumPy for data analysis  
- Matplotlib for visualization  
- Jupyter Notebook / VS Code  

---

## Project Objectives
- Analyze overall sales and profit trends  
- Identify top-performing product categories  
- Study regional and state-wise profitability  
- Understand the impact of discounts on profit  
- Generate practical business insights  

---

## Key Insights
- The **Technology** category generates the highest sales.
- **California and New York** are the most profitable states.
- High discounts often lead to reduced profit margins.
- Some sub-categories generate losses despite good sales volume.

---

## Summary Statistics
- **Total Sales:** 2,297,200.86  
- **Total Profit:** 286,397.02  
- **Total Orders:** 5,009  
- **Top Category:** Technology  
- **Top State by Profit:** California  

---

## Conclusion
The analysis shows that business performance is strongly influenced by product category, discount strategy, and regional demand. Focusing on high-margin products and optimizing discounts can significantly improve profitability.
