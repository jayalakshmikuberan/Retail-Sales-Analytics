# Retail Sales and Inventory Analytics Dashboard

## Project Description

This project focuses on analyzing retail sales and inventory data to understand business performance and stock movement. The dashboard provides clear insights into sales trends, product performance, and inventory status, helping decision-makers take informed actions based on data.

The goal of this project is to simulate a real-world retail analytics use case using practical data analysis and visualization techniques.

---

## Problem Statement

Retail businesses often struggle to track sales performance and manage inventory efficiently at the same time. Lack of proper analysis can lead to overstocking, stockouts, and missed revenue opportunities. This project addresses these challenges by analyzing sales and inventory data in a structured and visual manner.

---

## Objectives of the Project

* Analyze overall sales performance across time
* Identify top-performing and low-performing products
* Monitor inventory levels and stock movement
* Understand category-wise revenue contribution
* Generate meaningful business insights to support decision-making

---

## Dataset Overview

The dataset used in this project contains retail transaction and inventory-related information such as:

* Order and sales details
* Product and category information
* Quantity sold and revenue values
* Inventory and stock-related attributes


This dataset represents a typical retail environment and is suitable for sales and inventory analysis.

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/retail-sales-inventory-analytics.git
   ```
2. Navigate to the project directory
3. Install required libraries:

   ```bash
   pip install -r requirements.txt
   ```
4. Open the Jupyter Notebook:

   ```bash
   jupyter notebook
   ```
5. Run the analysis notebook to view results and visualizations
