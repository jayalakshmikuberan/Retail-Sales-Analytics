# Retail-Sales-Analytics

## Project Overview
This project focuses on analyzing retail sales and inventory data to generate meaningful business insights. The workflow includes data cleaning, SQL analysis, KPI generation, and dashboard creation using Power BI.

The objective is to help businesses understand sales performance, inventory trends, customer behavior, and key business metrics through data-driven analysis.
