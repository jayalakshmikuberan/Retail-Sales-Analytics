# Retail Sales & Inventory Analytics Dashboard

## Dashboard Components

1. KPI Cards
   - Total Revenue
   - Total Quantity Sold
   - Average Sales
   - Total Transactions

2. Charts
   - Monthly Sales Trend
   - Product Sales Chart
   - Gender-wise Sales Distribution
   - Category Revenue Contribution

3. Filters
   - Gender Filter
   - Product Category Filter
   - Date Filter

## Features

- Interactive dashboard
- Dynamic filtering
- Revenue analysis
- Customer analysis
- Product category analysis

## Insights

- Electronics generated highest revenue
- Female customers contributed slightly higher sales
- Peak sales observed during May and October

## Tools Used

- Power BI
- GitHub
- Dataset Cleaning
